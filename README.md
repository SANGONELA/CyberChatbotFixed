# PROG6221 Part 2 - Cybersecurity Chatbot

## Features
1. Keyword Recognition: password, phishing, privacy, scam, malware, browsing
2. Random Responses: Dictionary<string, List<string>> + single Random
3. Conversation Flow: tell me more, give me another tip, what else
4. Memory: MemoryStore stores UserName and FavouriteTopic
5. Sentiment: detects worried, curious, frustrated
6. Error Handling: blank and unknown input handled
7. Collections: List, Dictionary, delegate BotResponseHandler
8. GUI: ASCII label, voice greeting with relative path
9. GitHub Actions CI, 6 commits, 3 tags

## How to Run
Open CyberChatbotFixed.sln > F5 > Type: my name is John, Tell me about password safety, Tell me more, I am worried about scams
